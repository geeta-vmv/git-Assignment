# Assignment 01: 15 Essential Git Commands

| Sr. No. | Command | Description |
| :--- | :--- | :--- |
| 1 | `git init` | Initializes a new local Git repository. |
| 2 | `git clone <url>` | Downloads a copy of a remote repository to the local machine. |
| 3 | `git status` | Displays the state of the working directory and staging area. |
| 4 | `git add <file>` | Adds a specific file to the staging area. |
| 5 | `git add .` | Stages all new and modified files for the next commit. |
| 6 | `git commit -m "message"` | Saves staged changes permanently in history with a descriptive message. |
| 7 | `git log` | Shows the complete commit history of the repository. |
| 8 | `git log --oneline` | Displays a compact, single-line summary of each commit. |
| 9 | `git branch` | Lists all local branches or creates a new branch (`git branch <name>`). |
| 10 | `git checkout -b <name>` | Creates a new branch and switches to it immediately. |
| 11 | `git merge <branch>` | Merges changes from the specified branch into the current branch. |
| 12 | `git remote add origin <url>` | Links a local repository to a remote GitHub repository URL. |
| 13 | `git push -u origin main` | Uploads local commits to the remote repository on GitHub. |
| 14 | `git pull origin main` | Fetches and merges latest changes from the remote repository. |
| 15 | `git diff` | Shows line-by-line differences between unstaged changes and the last commit. |
